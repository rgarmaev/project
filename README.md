# sol-arb

Кросс-биржевой арбитражный бот для SOL/USDT. Одновременно следит за стаканами на Binance, Bybit и MEXC, выявляет ценовые расхождения между спотовыми и фьючерсными рынками и выставляет парные ордера на покупку и продажу, когда чистый спред превышает заданный порог.

## Как это работает

1. **Ценовые потоки** — пять WebSocket-соединений транслируют live book tickers (Binance спот + фьючерс, Bybit спот + фьючерс, MEXC спот).
2. **Детектор** — каждую миллисекунду сканирует все пары рынков, считает чистый спред с учётом комиссий и проскальзывания, отправляет сигнал при спреде ≥ `min_spread_pct`.
3. **Исполнитель** — получает сигналы, проверяет риск-параметры, выставляет одновременные ордера на покупку и продажу, фиксирует результат.
4. **Дашборд** — React-интерфейс на порту 3001, получает обновления в реальном времени по WebSocket.

## Требования

- Rust 1.78+ (`cargo`)
- Node.js 18+ и npm (для дашборда)

## Установка

```bash
# 1. Клонировать и собрать
git clone https://github.com/rgarmaev/project.git
cd project
cargo build --release

# 2. Заполнить учётные данные

# Вписать API-ключи в .env

# 3. Собрать дашборд (один раз)
cd dashboard
npm install
npm run build
cd ..
```

## Конфигурация

Все торговые параметры находятся в `config.toml`. API-ключи можно переопределить переменными окружения.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `trading.symbol` | `SOL` | Базовый актив |
| `trading.min_spread_pct` | `0.001` | Минимальный чистый спред для сделки (0.1%) |
| `trading.trade_size_usdt` | `200` | Объём каждой ноги в USDT |
| `trading.max_slippage_pct` | `0.0005` | Максимальное допустимое проскальзывание |
| `trading.paper_trading` | `true` | Симуляция ордеров без реального исполнения |
| `risk.max_position_usdt` | `2000` | Максимальная суммарная открытая позиция |
| `risk.max_daily_loss_usdt` | `100` | Дневной лимит убытков |
| `risk.max_open_trades` | `3` | Лимит одновременных сделок |
| `risk.cooldown_ms` | `500` | Минимальный интервал между сигналами (мс) |

API-ключи задаются в `config.toml` или через переменные окружения:

```
BINANCE_API_KEY / BINANCE_API_SECRET
BYBIT_API_KEY   / BYBIT_API_SECRET
MEXC_API_KEY    / MEXC_API_SECRET
```

Для подробных логов: `RUST_LOG=sol_arb=debug`.

## Запуск

```bash
# Бумажная торговля (по умолчанию, реальных ордеров нет)
cargo run --release

# Реальная торговля — установить paper_trading = false в config.toml
cargo run --release
```

Дашборд доступен по адресу `http://localhost:3001`.

## Дашборд

Построен на React + Recharts. Отображает:

- График накопленного PnL
- Актуальные цены по всем рынкам
- Ленту последних сделок
- Метрики: количество сделок, процент прибыльных, суммарный PnL, комиссии, максимальная просадка, среднее время исполнения

Дашборд раздаётся как статика из `dashboard/dist/` встроенным HTTP-сервером (Axum). После изменений UI пересобрать командой `npm run build` в папке `dashboard/`.

## Риск-менеджмент

`RiskManager` проверяет четыре условия перед каждым ордером:

- Лимит одновременно открытых сделок
- Дневной лимит убытков
- Ожидаемый PnL должен быть положительным
- Cooldown между сигналами
